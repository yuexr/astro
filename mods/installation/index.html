Installing Astroneer mods

These instructions are for my Astroneer mods on Windows PC

Currently I recommend Vortex and AstroModLoader-Classic installation.
Other mod loaders may be compatible but no support will be provided.

Vortex Mod Manager

  1. Download and install Nexus Mods Vortex.
  2. Find Astroneer in Vortex's Games section and select Manage. Accept the required extension and dependency prompts. UE4SS and AutoIntegrator will be automatically installed.
  3. File download:
    • If downloading from Nexus Mods, select Vortex option or click Mod Manager download. The download will start automatically in Vortex.
    • If downloading from other direct sources, drag the mod's .zip file to the Drop File module at the bottom.
  4. Enable desired mods, deploy if prompted, and launch the game!
Mods downloaded directly from Nexus Mods through Vortex support automatic update detection.

AstroModLoader Classic

  1. Download and open AstroModLoader Classic .exe file.
  2. Select your Astroneer installation if prompted.
  3. Open Settings and click Install UE4SS. This will automatically install all UE4SS dependencies such as ConsoleCommandsMod.
  4. Drag the downloaded mod's .zip into the loader window.
  5. Enable desired mods and launch the game!

AstroModLoader Classic supports automatic update detection for my mods.
Please ensure you are using AstroModLoader Classic and NOT AstroModLoader.

Manual UE4SS installation (not recommended)

This method works only for UE4SS mods. Installation with Vortex or AML-C is still recommended.

  1. Download the latest UE4SS experimental release .zip file (scroll to bottom under assets)
  2. In Steam, right-click Astroneer → Manage → Browse local files. Open Astro\Binaries\Win64.
  3. Extract UE4SS .zip content into Astro\Binaries\Win64.
  4. Extract the mod's .zip into Astro\Binaries\Win64\ue4ss\Mods, keeping the included mod folder intact.
  5. Check that the mod folder sits directly inside Mods.
    • Your folder structure should look something like this: ASTRONEER\Astro\Binaries\Win64\ue4ss\Mods\ModName.
