I really like protecting the original terrain! I particularly hate the destruction of flora and environmental objects as they really add to each planet's character but they cannot be regenerated... 😔

Alas, the [mod I found](https://atenfyr.com/ams-archive/mod?mod=WeakDynamiteMod.Colson) that could alleviate this problem was outdated and also did not have the granular controls I desired, so it inspired me to make my own.

(Besides, blowing up EXO caches really shouldn't be such a violent ordeal.)

This was my first mod that used UE4SS console commands so it was fun to navigate the UX of that. I had to think about how users might interpret the commands and how to minimize accidents.
