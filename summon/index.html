List of items that can be summoned into the game with UE4SS console commands.

Back up your saves before using. Some summon commands may cause unexpected behaviour, especially flagged items. Use at your own risk.

How to use & about this list

How to use

  1. Install UE4SS. See my installation guide.
    • The ConsoleCommandsMod add-on is automatically included with Vortex/AML-C instructions above.
  2. Load a separate test save and open the in-game console by pressing F10 or tilde.
  3. Find an item using the search or filters, then click Copy.
  4. Paste the complete command into the console and press Enter.
